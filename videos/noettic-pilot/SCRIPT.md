# Pilot script — AI voice skill

One segment per scene. Each segment is rendered to its own audio file so the
scene length always matches the narration.

## 01-hook
Your AI writes like everyone else's AI. Same openers. Same tired phrases. And your customers can tell.

## 02-title
So build a fix inside Claude. It's called a voice skill, and it takes about ten minutes.

## 03-what
A skill is a file Claude reads before it writes. It holds your rules: how you sound, what you never say, how you end. Claude only loads it when the job needs it.

## 04-step1
Step one. Give Claude ten pieces of your best writing. Posts, emails, anything that sounds like you.

## 05-step2
Step two. Ask Claude to study them and write the skill. It pulls out your sentence length, your favorite words, and the phrases you would never use.

## 06-step3
Step three. Ask for a LinkedIn post. Claude loads the skill first, then writes.

## 07-twist
The first drafts will still slip. Old habits like "here's the thing" creep back in. So add a second skill: a reviewer. It checks every draft against your banned list before you ever see it.

## 08-close
The starter skill is linked below. Teach it once, and every draft starts sounding like you.
